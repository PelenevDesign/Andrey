# Art Stone — копия сайта art-stone.site

Статический сайт без сборки и без зависимостей: HTML + CSS + немного JS.

## Как открыть

Из папки «Андрей Валентинович» (на уровень выше этой):

```bash
python -m http.server 8765 --directory art-stone-copy
```

Затем открыть http://localhost:8765/ . Страницы можно открывать и двойным кликом по `index.html`,
но через локальный сервер надёжнее (карта, шрифты, видео).

## Файлы стилей и скриптов

- `css/style.css` — общие стили: шапка, меню, кнопки, hero и секции главной, подвал, попапы, форма.
- `css/zero.css` — раскладка «свободных» блоков: элементы позиционируются по сетке 1200/960/640/480/320 px, как у оригинала.
- `css/pages.css`, `css/blocks.css` — компоненты внутренних страниц (галереи, шаги, карточки, слайдер, горизонтальная прокрутка шагов и т. д.).
- `css/article.css` — страницы статей.
- `css/b2b.css`, `js/b2b.js`, `js/metrika.js` — страница для строительных компаний: стили, заявка, цели Метрики, UTM-метки.
- `js/main.js` — меню, слайдер, аккордеон, попапы, формы, карта.
- `js/pages.js` — лайтбокс галерей, слайдер-галерея, видео-попап, формы в блоках, горизонтальная прокрутка шагов на «Панно».

## Что нужно доделать при переносе на свой хостинг

- **Картинки** лежат локально в `img/` (231 файл, около 61 МБ, оригиналы без пересжатия). Для ускорения загрузки их стоит прогнать через оптимизатор (WebP, уменьшение гигантских PNG).
- **og:image** (картинка для превью в соцсетях) оставлена абсолютной ссылкой на CDN оригинала: соцсети требуют полный URL. После переноса замените её на адрес вашей картинки.
- **Шрифты** (Google Fonts), **карта** (Яндекс) и **видео** (YouTube) подключаются по сети.
- **Страница для строительных компаний.** Все места, которые нужно подтвердить у заказчика, помечены комментарием `<!-- TODO: уточнить у заказчика … -->` в `stroitelnym-kompaniyam.html` (найти поиском по «TODO: уточнить у заказчика»); на самой странице недостающие данные подсвечены жёлтым пунктиром. Форма не отправится на боевом домене, пока не задан `window.B2B_FORM_ENDPOINT` (или общий `window.FORM_ENDPOINT`): иначе посетитель увидит сообщение с телефоном вместо ложного «отправлено».
- **Яндекс Метрика** (счётчик 88022855) подключена только на страницах для строительных компаний (`js/metrika.js`). На локальных адресах вместо неё работает заглушка, чтобы не портить статистику. На остальные страницы копии счётчик не ставился.
- **Адреса без `.html`.** Страница должна открываться как `/stroitelnym-kompaniyam`; на хостинге нужна обычная настройка «чистых» адресов (rewrite), в canonical и sitemap уже указаны адреса без расширения.
- **Формы** (константа `window.FORM_ENDPOINT` в `js/main.js`) пока только проверяют поля и показывают сообщение об успехе. Чтобы заявки уходили, укажите адрес обработчика (почта, CRM, Formspree и т. п.).
- **canonical и og:url** в `<head>` всех страниц указывают на `https://art-stone.site/…`. После публикации копии на другом адресе замените их на новый домен, иначе поисковики сочтут копию дублем оригинала.
- **Метрика/аналитика** оригинала не переносилась.

## Загрузка на Бегет (хостинг Apache + PHP)

Содержимое папки целиком копируется в `public_html`. Нужные файлы уже в проекте:
- `.htaccess`: адреса без `.html` (/gidrorez), 301 со старых адресов, сжатие, кэш, страница 404.
- `404.html`, `robots.txt`, `sitemap.xml`.
- `send.php`: приём заявок (письмо на km89r@mail.ru, вложения для страницы «Строительным компаниям»). Формы отправляют на `/send.php` автоматически на любом домене, кроме localhost и github.io.
